# portfolio-v3

Portafolio personal con estética inspirada en World of Warcraft.

Stack: Vite + React 19 + TypeScript + Tailwind CSS v4 + shadcn/ui (componentes 8bitcn).

## Scripts

```bash
pnpm install
pnpm dev       # servidor de desarrollo
pnpm build     # tsc + vite build
pnpm lint      # eslint
```

## Estructura destacada

- `src/components/wow/` — barra de buffs (arriba a la derecha) y Micro Bar de ventanas multi-abiertas (abajo a la derecha), estilo WoW.
- `src/data/` — skills y secciones del menú.
- `public/` — assets organizados por categoría (`tech/`, `companies/`, `game/`, `projects/`, `social/`, `avatar/`).

## Atajos de teclado

- `C` Hoja de personaje · `L` Registro de misiones · `P` Grimorio · `Y` Logros · `J` Hermandad
- `Esc` cierra la ventana enfocada
